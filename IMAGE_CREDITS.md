# Image credits

Every photo below is sourced from Pexels or Unsplash, both of which license
their catalogues for free commercial and personal use with no attribution
required. This file is a transparency gesture, not a license requirement —
consistent with a course whose own ethics section is about disclosure, not
permission. See `PROCESS.md` for why real photography appears in this repo
at all, after an earlier pass had explicitly ruled it out.

No image on this site is AI-generated. The site's invented "AI slop"
artefacts remain hand-authored SVG/CSS, standing in for a genre the course
argues shouldn't illustrate itself with the real thing.
